# TokensLab releases

Public installers for [TokensLab](https://tokenslab.com).

This repository holds **GitHub Releases only** — Windows `.exe` and Linux `.AppImage` (macOS `.dmg` after signing). The desktop app source is private.

Download from [tokenslab.com/download](https://tokenslab.com/download), or the [latest release](https://github.com/lucasbarroos/tokenslab-releases/releases/latest).

- **Windows:** if SmartScreen appears, choose More info → Run anyway.
- **Linux:** `chmod +x TokensLab-linux.AppImage` then run it.
